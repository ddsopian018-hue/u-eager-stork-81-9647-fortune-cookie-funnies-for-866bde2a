One line for make.fun's "Fortune Cookie Funnies for Engineers" bounty ($2 prize): a Friday deploy that passes every test, then pages you at 3:12 a.m. on Saturday from the one endpoint nobody on the team owns. The fortune is the gap between a green CI pipeline and the unowned endpoint that only ever fails while you are asleep.

## Run it

```sh
python3 main.py
```

It writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
